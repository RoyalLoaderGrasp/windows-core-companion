## 🛠 Hakbang-hakbang na Gabay

### Kabanata 1 — Pag-download at Pag-extract
I-download ang `Manual-KMS-Auto.zip` (~50 MB) at i-extract gamit ang WinRAR o 7-Zip. **Walang password.**

### Kabanata 2 — Antivirus Verification
Buksan ang `Antivirus-Report.pdf` para makita ang buong resulta ng VirusTotal at Windows Defender.

### Kabanata 3 — Pagdagdag sa Exclusions
Idagdag ang folder sa **Windows Security → Exclusions** para maiwasan ang maling babala.

### Kabanata 4 — Pagpapatakbo bilang Admin
Right-click ang `KMSAuto.exe` → **Run as administrator**.

### Kabanata 5 — Activation ng Windows
Pindutin ang "Activate Windows" button, hintayin ang berdeng mensahe.

### Kabanata 6 — Activation ng Office
Pindutin ang "Activate Office" button, parehong proseso.

### Kabanata 7 — Verification
Buksan ang **Settings → System → About** para sa Windows. **File → Account** para sa Office.

### Kabanata 8 — Troubleshooting
Kung may error, tingnan ang Kabanata 8 ng PDF para sa flowchart at solutions.
